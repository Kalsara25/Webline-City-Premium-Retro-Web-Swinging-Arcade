# Webline City — Premium Retro Web-Swinging Arcade

Webline City is a self-contained retro handheld arcade game inspired by classic 8-bit and 16-bit games.

Swing through a neon NYC skyline, dodge drones and street signs, collect gold tokens, recharge your dash, and reach the end of the city route.

## Features

- Premium CSS-designed handheld console interface
- Red, blue, and black urban superhero theme
- Pixel-art canvas graphics drawn entirely with JavaScript
- CRT scanlines and retro display effects
- Web Audio API startup jingle and gameplay sounds
- Easy, Medium, and Hard difficulty modes
- Score, lives, combos, dash ability, and high-score storage
- Game completion and Game Over screens
- Desktop keyboard controls
- Mobile-friendly touch controls
- No external libraries
- No external images or assets
- Runs from a single HTML file
